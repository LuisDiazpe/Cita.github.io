# Cita Random: ¿Sin ideas para una cita? 🎲💞  

## Descripción 📜  
Esta aplicación está diseñada para esos momentos en los que no tienes idea de qué hacer para una cita. Con solo presionar un botón, la aplicación selecciona **de manera aleatoria** un plan para tu cita y te lo muestra, ayudándote a salir de la rutina y sorprender a tu acompañante.  

Además, incluye una funcionalidad especial que muestra la dirección IP del usuario cuando interactúa, añadiendo un toque tecnológico interesante.  

**Enlace al proyecto**: [Cita Random](https://luisdiazpe.github.io/Cita.github.io/)  

---

## Características ✨  

1. **Planificación de citas al azar**:  
   - Presiona un botón y obtén una actividad aleatoria para hacer en tu cita.  
   - Actividades variadas y divertidas para adaptarse a diferentes gustos.  

2. **Función de IP**:  
   - Muestra la dirección IP del usuario al presionar el botón, añadiendo un elemento de interacción tecnológica.  

3. **Diseño visual atractivo**:  
   - Una interfaz simple y agradable que se enfoca en la experiencia del usuario.  
   - Inspirada en un diseño de ticket para resaltar el carácter lúdico de la aplicación.  

---

## Cómo usarla 🚀  

1. **Abrir la aplicación**:  
   Accede al sitio web mediante el enlace proporcionado: [Cita Random](https://luisdiazpe.github.io/Cita.github.io/).  

2. **Presiona el botón**:  
   Haz clic en el botón principal de la aplicación.  

3. **Descubre tu plan**:  
   La aplicación seleccionará automáticamente una actividad para la cita y la mostrará en pantalla.  

4. **Información adicional**:  
   - También podrás ver tu dirección IP al presionar el botón, como parte de la experiencia interactiva.
